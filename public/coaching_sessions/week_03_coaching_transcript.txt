ASSISTANT
Understanding paths is important in Linux, Node.js, Express, and EJS.
Linux filesystem paths and web URL paths are not interpreted in exactly the same way.
Example project:
/home/boy/projects/myapp/
├── server.js
├── package.json
├── public/css/style.css
├── views/index.ejs
├── views/partials/header.ejs
└── controllers/projectController.js
Assume terminal is in /home/boy/projects/myapp.
Linux paths:
 / means filesystem root, e.g. /home/boy
 ./ means current directory, e.g. ./server.js
 ../ means parent directory
 ~/ means home directory (shell expansion)
 public/ is relative to current directory.
./server.js and server.js refer to the same pathname, but executing a command can differ because Bash searches PATH.
Web URL paths:
 /organization/3 resolves from the website root, e.g. http://localhost:3000/organization/3.
 organization/3 and ./organization/3 resolve relative to the current page's URL.
Question 13: If your terminal is inside /home/boy/projects/myapp and you execute cd /public, where will Linux look, and why?

USER
at the root.
My dilema stems from using when to use a slash to locate a file and whether or not to use a slash to locate a directory.

ASSISTANT
Correct. Linux will look for /public directly under the filesystem root.
The slash is not determined by whether you're accessing a file or directory. It's determined by the path's location and structure.
Assuming current directory /home/boy/projects/myapp:
public: directory inside current directory
public/: same directory, trailing slash explicitly indicates directory access
./public: same directory, explicitly relative
/public: directory under filesystem root
public/style.css: file inside public
./public/style.css: same file, explicitly relative
/public/style.css: file under /public at filesystem root
../public: directory public in parent directory
Three rules:
1. Leading / starts from filesystem root.
2. ./ starts from current directory and is usually optional.
3. / between names separates path components.
cd public, cd ./public, cd public/, cd ./public/ are equivalent; cd /public is different.
